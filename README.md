# Disney+ Movies and TV Shows — Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Disney+ Movies and TV Shows dataset using Python. The objective is to understand the content available on Disney+ through data cleaning, statistical analysis, and visualizations.

## Dataset
- **Dataset:** Disney+ Movies and TV Shows
- **Rows:** 1,450
- **Columns:** 12
- **Format:** CSV
- **File:** `disney_plus_titles.csv`

## Tools & Libraries
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
- Dataset structure and overview
- Duplicate row check
- Missing value analysis
- Numerical summary statistics
- Categorical data analysis
- Data visualization
- Key findings and insights

## Visualizations
The project includes five visualizations:
1. Content type distribution
2. Release year distribution
3. Content rating distribution
4. Movies vs TV Shows percentage
5. Top genres

## Key Findings
- Movies make up approximately 72.6% of the dataset.
- TV Shows account for approximately 27.4%.
- Missing values are most prominent in the director column.
- The dataset contains content from various release years.
- Family, Animation, and Comedy are among the most prevalent genres.

## How to Use
1. Download the notebook and dataset from this repository.
2. Open the notebook using Google Colab or Jupyter Notebook.
3. Ensure the CSV file is in the correct location.
4. Run the notebook cells sequentially.
